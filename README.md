# Zaper

Приложение для Windows 10/11 x64. Версия **3.8.1**. Нативный [Linux-порт](linux/README.md): **3.8.1-linux.2**, x86_64/ARM64.

Управление службой winws2, профилями TCP/UDP, исключениями приложений, диагностикой FACEIT и автоподбором стратегии. Крестик и сворачивание скрывают окно в трей; полный выход доступен в меню трея.

## Изменения 3.8.1

- В списке выбора исключений показаны настоящие иконки EXE; поиск сохраняет отмеченные приложения.
- **Настройки запуска и трея** перенесены на вкладку **Настройки**. В этом окне собраны запуск свёрнутым, автозапуск панели, автозапуск службы и уведомления.
- Сохранение параметров запуска меняет тип запуска службы без её перезапуска. При ошибке записи настроек возвращаются прежние параметры SCM и планировщика.
## Изменения 3.8.0 по замечаниям тестера

- Приложение называется **zaper**. В заголовке больше нет «самостоятельное приложение»; EXE, установщик и трей используют один знак Z. Имя внутреннего EXE и каталог установки сохранены для совместимости с предыдущими версиями.
- Ручные подтверждения голоса/экрана Discord удалены из проверки сети и автоподбора. Выбор стратегии использует автоматические HTTPS, QUIC и STUN пробы. Они не подтверждают реальный звонок, демонстрацию или вход в матч.
- График задержки и нагрузки встроен в диагностику. По умолчанию выбран сетевой адаптер текущего интернет-маршрута.
- Запуск свёрнутым исправлен, параметр `--tray` сохраняется при повышении прав. Настройки поведения описывают каждую опцию; управление автозапуском панели и службы остаётся раздельным.
- IP-список загружается напрямую и через доступный системный proxy; есть резервный адрес GitHub API, проверка содержимого и откат при ошибке применения. При недоступности источников прежний список сохраняется.
- **Hosts** — редактируемое окно с проверкой записей, загрузкой предложенных записей и резервной копией перед сохранением. Загрузка не пишет системный файл до нажатия «Сохранить»; сторонние изменения обнаруживаются.
- Окно «О приложении» оформлено в общей теме, исправлены переводы строк.
## Удобство в версии 3.7.0

- «Проверить и исправить» восстанавливает повреждённые компоненты из встроенной копии, проверяет конфигурацию и сохраняет пользовательские списки.
- ZIP диагностики содержит состояние служб, настройки и последние журналы. Токены, пароли и имя папки пользователя скрываются; перед передачей проверьте содержимое архива.
- История настроек позволяет вернуть предыдущую конфигурацию. Есть готовые профили «Обычный» и «Игры + Discord», сохранение своего профиля и импорт/экспорт JSON. Отсутствующие на другом ПК EXE пропускаются.
- Выбор исключений доступен из списка обнаруженных приложений с поиском и вручную через EXE. Изменения применяются кнопкой «Сохранить».
- Настройки трея: запуск свёрнутым, отдельный автозапуск панели и уведомления об ошибках. Автозапуск панели использует задачу Windows текущего пользователя; автозапуск службы управляется отдельно.
- Обновление приложения отделено от обновления движка. Для закрытого GitHub нужен доступ через браузер или токен с чтением Contents; токен живёт только в окне обновления. Автозагрузка проверяет SHA-256 из метаданных релиза.
- График показывает ICMP-задержку выбранного адреса и скорость выбранного сетевого адаптера. Отсутствие ответа ICMP не доказывает недоступность игрового сервера; график не меняет маршрутизацию.

Для пересылки на другой Windows 10/11 x64 достаточно установщика: движок, библиотеки, фейки и копия восстановления включены. Нужны права администратора и .NET Framework 4.8. Установка поддерживает обновление существующей версии с сохранением настроек.
## Структура

- `src/` — актуальный исходный код приложения и проверок на C#.
- `installer/` — сценарий установщика Inno Setup.
- `vendor/runtime/` — сторонние компоненты, публичные списки и фейки.
- `build.ps1` — сборка приложения и установщика.
- `build/`, `dist/` — результаты сборки, исключены из Git.

## Сборка

Нужны Windows x64, .NET Framework 4.8 и Inno Setup. Компилятор Inno Setup не включён в репозиторий.

Только приложение:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -SkipInstaller
```

Приложение и установщик:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -InnoCompiler "C:\Program Files (x86)\Inno Setup 7\ISCC.exe"
```

Результат: `dist/Zapret2Manager-Setup-3.8.1-x64.exe`. Сборка не устанавливает приложение и не меняет службы.

## Проверки

Исходники проверок включены в `src/`. Интеграционные проверки служб требуют Windows, прав администратора и отдельного тестового окружения. Сетевые пробы не подтверждают вход в настоящий матч FACEIT.

## Изменения

- 3.6.1: убраны доменные фильтры из профиля неизвестного игрового UDP. Они мешали выбору профиля без hostname. IPSet и IP-исключения сохранены.
- 3.6.2: управление из системного трея.
- 3.7.0: восстановление, история, профили, ZIP диагностики, выбор приложений, настройки трея, обновление панели и график сети.
- 3.6.3: крестик скрывает окно в трей; полный выход — отдельным пунктом.

Пользовательские настройки находятся в `%ProgramData%\zapret2` и не включены в репозиторий. Журналы пользователей, дампы пакетов и секреты авторизации не включены.
