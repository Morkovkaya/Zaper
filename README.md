# Zapret 2 Manager

Приложение для Windows 10/11 x64. Версия **3.6.3**. Дополнительно доступен нативный [Linux-порт](linux/README.md) **3.6.3-linux.1** для x86_64 и ARM64 (предварительная версия).

Готовые сборки и контрольные суммы: [GitHub Releases](https://github.com/ivanmorkovka1-ux/zaper2/releases). Windows-релиз собирается из исходного коммита 3.6.3; Linux публикуется отдельно как prerelease.

Управление службой winws2, профилями TCP/UDP, исключениями приложений, диагностикой FACEIT и автоподбором стратегии. Крестик и сворачивание скрывают окно в трей; полный выход доступен в меню трея.

## Структура

- `src/` — актуальный исходный код приложения и проверок на C#.
- `installer/` — сценарий установщика Inno Setup.
- `vendor/runtime/` — сторонние компоненты, публичные списки и фейки.
- `build.ps1` — сборка приложения и установщика.
- `linux/` — нативные CLI, GUI, установка, systemd и проверки Linux.
- `scripts/package-linux.py` — универсальный Linux-архив с проверенным runtime и исходниками движка.
- `.github/workflows/build.yml` — сборка и проверки Windows/Linux на независимых runners.
- `build/`, `dist/` — результаты сборки, исключены из Git.

## Сборка

Нужны Windows x64, .NET Framework 4.8 и Inno Setup. Компилятор Inno Setup не включён в репозиторий.

Только приложение:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -SkipInstaller
```

Приложение и установщик:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -InnoCompiler "C:\Program Files (x86)\Inno Setup 7\ISCC.exe"
```

Результат: `dist/Zapret2Manager-Setup-3.6.3-x64.exe`. Сборка не устанавливает приложение и не меняет службы.

## Проверки

Исходники проверок включены в `src/`. Интеграционные проверки служб требуют Windows, прав администратора и отдельного тестового окружения. Сетевые пробы не подтверждают вход в настоящий матч FACEIT.

Windows CI проверяет все режимы и стратегии, STUN/relay, отмену операций, интерфейс/трей, тестовую службу и изолированную установку/удаление. Linux CI проверяет все профили обоих процессоров, GUI и обработку реальных пакетов в отдельном network namespace. Эти проверки не подтверждают доступность сервисов в сети конкретного провайдера.

## Изменения

- 3.6.1: убраны доменные фильтры из профиля неизвестного игрового UDP. Они мешали выбору профиля без hostname. IPSet и IP-исключения сохранены.
- 3.6.2: управление из системного трея.
- 3.6.3: крестик скрывает окно в трей; полный выход — отдельным пунктом.

Пользовательские настройки находятся в `%ProgramData%\zapret2` и не включены в репозиторий. Журналы пользователей, дампы пакетов и секреты авторизации не включены.
